# Hikari — 運用ナレッジアシスタント

[English README](../README.md)

Budi Juartoが2026年10月に作成した、Python・FastAPI・MCPのポートフォリオ用デモです。架空の英語・日本語の運用文書から関連する段落を検索し、原文、ファイル名、行番号、文書のSHA-256を表示します。実際の雇用主の方針、過去の顧客案件、本番導入実績を示すものではありません。

## ローカルで実行する

Python 3.11以上が必要です。標準のオフラインモードでは、APIキー、GPU、LLMのダウンロードは不要です。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install ".[test]"
.venv\Scripts\python.exe -m uvicorn ai_ops.api:app --host 127.0.0.1 --port 8000
```

ブラウザーで <http://127.0.0.1:8000> を開きます。APIの操作画面は <http://127.0.0.1:8000/docs> です。macOS/LinuxではPythonのパスを `.venv/bin/python` に変更してください。

質問例:

* 「重大障害のエスカレーションと復旧手順は？」
* 「バックアップ復元テストの頻度は？」
* 「不可逆のデータベース移行後はロールバックが安全ですか？」

言語の選択は検索対象の文書を絞り込みます。自動翻訳ではありません。英語の質問には英語、日本語の質問には日本語を選択してください。検索された文章が質問全体に答えているとは限らないため、適用条件を人が確認する必要があります。

## 実装のポイント

1. Markdown文書を見出しと段落で分割します。段落全体を保持して、否定表現や条件の脱落を防ぎます。
2. 英語の単語と日本語の文字n-gramを使ったBM25で検索します。ベクトル検索、埋め込み、ファインチューニングは実装していません。
3. 引用には文書ID、ファイル、見出し、行番号、ハッシュ、検索スコアを付けます。回答は原文の抜粋です。
4. REST APIとMCPが同じサービスとPydanticの検証を使用します。MCPは公式Python SDK `mcp==2.3.0`を使用しています。
5. 任意のOllama連携は、検索済みの段落を選択する機能に限定しています。未知のID、重複、改変、段落の切り詰め、無効なJSON、通信エラーを検出した場合は、元の検索結果へフォールバックします。

操作承認、メッセージ送信、コマンド実行、実システムへの変更は行いません。

## MCPツール

`search_documents`、`answer_question`、`read_document`を提供します。リソースは `ops://catalog` と `ops://documents/{document_id}` です。

```powershell
.venv\Scripts\python.exe -m ai_ops.mcp_server
```

このコマンドは標準入出力でMCPクライアントの接続を待ちます。実際の接続例は次のデモで確認できます。

```powershell
.venv\Scripts\python.exe -m ai_ops.demo
```

ツールの一覧、ネゴシエーションされたプロトコルバージョン、引用付き回答をUTF-8 JSONで出力します。構成例とOllamaの設定は英語READMEに記載しています。

## 評価とテスト

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ai_ops.evaluate
```

テストは引用と原文の一致、検索順位、範囲外の質問、入力検証、任意のパスの拒否、LLM応答の改変と障害、公式MCP SDK、実際のstdio子プロセス通信を確認します。

評価は同じ6文書に対して人が作成した20件の該当質問と6件の範囲外質問を使用します。文書・段落のRecall、MRR、範囲外質問の棄却率を記録します。小規模な回帰テストであり、未知の文書での性能や本番精度を示すものではありません。質問セットと測定結果を公開して再現できるようにしています。

## Docker

```powershell
docker compose up --build
```

公開先はローカルの `127.0.0.1:8000` のみです。非rootユーザー、読み取り専用ファイルシステム、オフラインモードで実行します。終了時は `docker compose down` を実行してください。認証や本番用の運用機能は未実装です。
